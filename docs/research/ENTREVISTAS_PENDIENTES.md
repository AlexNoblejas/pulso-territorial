# Validación con usuarios: pendiente

No se han realizado ni documentado las tres conversaciones exigidas por el curso en este proyecto. No se presentan entrevistas sintéticas como evidencia.

Entrevistar al menos a tres personas que realicen monitoreo territorial o elaboren reportes socioambientales. Registrar una nota separada por conversación, con fecha, rol, contexto y permiso para usar una síntesis anónima. Evitar datos personales innecesarios.

Preguntas: ¿cuándo hizo el último informe?, ¿qué fuentes consultó?, ¿cuánto tiempo tomó cada etapa?, ¿qué dato fue difícil de verificar?, ¿qué pasó cuando se omitió una novedad?, ¿qué herramienta utiliza hoy?, ¿qué necesitaría comprobar para pagar por este producto? Mostrar el flujo real después de preguntar por su experiencia.

Plantilla de nota: fecha; rol sin nombre; tarea reciente; fuentes y herramientas; tiempo/costo descrito; cita autorizada o paráfrasis identificada; reacción a la demo; objeción; precio propuesto y reacción; siguiente prueba acordada. No completar los campos sin evidencia.
